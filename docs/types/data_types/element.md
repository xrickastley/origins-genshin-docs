# Element

[Data Type](../data_types.md)

An [String](<https://origins.readthedocs.io/en/latest/types/data_types/string/>) used to specify one of [the seven Elements ↗](https://xrickastley.github.io/SevenElements/wiki/guide/elements/the_seven_elements) and **Physical**, indicating no element.

## Values

| Value		| Description											|
|-----------|-------------------------------------------------------|
|`PYRO`		| The <span class="pyro">**Pyro**</span> Element.		|
|`HYDRO`	| The <span class="hydro">**Hydro**</span> Element.		|
|`ANEMO`	| The <span class="anemo">**Anemo**</span> Element.		|
|`ELECTRO`	| The <span class="electro">**Electro**</span> Element.	|
|`DENDRO`	| The <span class="dendro">**Dendro**</span> Element.	|
|`CRYO`		| The <span class="cryo">**Cryo**</span> Element.		|
|`GEO`		| The <span class="geo">**Geo**</span> Element.			|
|`FREEZE`	| The <span class="cryo">**Freeze**</span> aura created by the [Frozen ↗](https://xrickastley.github.io/SevenElements/wiki/guide/elements/elemental_reactions/frozen) Elemental Reaction.|
|`BURNING`	| The <span class="pyro">**Burning**</span> aura created by the [Burning ↗](https://xrickastley.github.io/SevenElements/wiki/guide/elements/elemental_reactions/burning) Elemental Reaction.|
|`QUICKEN`	| The <span class="quicken">**Quicken**</span> aura created by the [Quicken ↗](https://xrickastley.github.io/SevenElements/wiki/guide/elements/elemental_reactions/quicken) Elemental Reaction.	|
|`PHYSICAL`	| The **Physical** Element, indicating *no Element*.	|
